GameDay uses Spotify Premium authentication and Spotify's Web Playback SDK to play directly inside supported desktop and mobile browsers. Desktop/Android browser players support a true Spotify volume fader. On iPhone/iPad, Spotify requires the physical device volume for the browser stream, so GameDay converts the music fader into a relative backing-track mix against the independently controlled announcement channel.
